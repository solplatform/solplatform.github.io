Для рекламодателей

Инструменты для управления рекламными кампаниями
в приложениях SolSIP и SolAgent

Калькулятор хэшей промо-изображений

Введите URL промо-изображения — получите SHA256 хэш для promo.json
Приложение сверяет хэш локального изображения с хэшем в promo.json.
Если хэши совпадают — показывает кэшированное изображение.
Если не совпадает — скачивает новое изображение.

SHA256:

Как использовать:

  1. Загрузите новое изображение на сервер
  2. Скопируйте URL изображения
  3. Вставьте URL в поле выше и нажмите "Рассчитать хэш"
  4. Скопируйте SHA256 хэш
  5. Вставьте хэш в поле portrait_sha256 или landscape_sha256 в promo.json
  6. Запуште изменения в репозиторий

Стратегия рекламной кампании

01

Гео-таргетинг

Реклама показывается в зависимости от региона, страны и города пользователя. Каскадная система: /promo/{CC}/{REG}/{City}.json → /promo/{CC}/{REG}.json → /promo/{CC}.json → /promo/WORLD.json

02

Тематическое таргетирование

Разные изображения для светлой и тёмной темы. Разные изображения для портретной и ландшафтной ориентации экрана.

03

Контроль показа

Рекламодатель задаёт дату окончания показа (valid_until). Пользователь может скрыть рекламу на 24 часа. Настройки отображения кнопки рекламы (размер, позиция, текст) доступны в настройках.

04

Кэш и обновление

Приложение кэширует изображения локально. При изменении хэша в promo.json — скачивает новое изображение. Это снижает трафик и ускоряет загрузку.

Архитектура рекламной системы

01

PromoBannerView

Загружает promo.json для текущей геолокации, выбирает изображение по теме и ориентации, кэширует в ImageView с помощью Coil3. Cache-busting по SHA256 хэшу.

02

PromoFragment

Настройки отображения рекламы: alpha, цвет канваса, размер и позиция кнопки эмодзи. Сохраняет настройки в SharedPreferences (promo_prefs).

03

AdBannerDialog

Показывает рекламный баннер при нажатии на кнопку эмодзи. Содержит изображение, описание и ссылку. Пользователь может перейти по ссылке или скрыть рекламу на 24 часа.

04

PromoViewModel

Управляет состоянием настроек рекламы. LiveData для emoji-текста, размера, позиции, зеркала. Сохраняет настройки в SharedPreferences.

Как работает счётчик:

Приложение отправляет анонимные метрики на бесплатный счётчик (Counter.dev).
Данные включают: страну, регион, город, тему (light/dark), ориентацию экрана.
Никаких персональных данных не собирается.
