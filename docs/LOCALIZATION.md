# Локализация

Проект поддерживает два языка:

- **English** (en) — язык по умолчанию
- **Русский** (ru)

## Страницы

### index.html
Поддерживает оба языка. Меню, контент и кнопки переводятся через систему `data-i18n`.

### advertisers.html
Только на русском языке. Меню на английском, контент на русском.

## Как работает переключение

Кнопки EN/RU в навигации переключают язык.
Выбранный язык сохраняется в `localStorage` и восстанавливается при следующем визите.
По умолчанию используется язык системы (`navigator.language`).

## Как добавить новый текст

1. Добавить ключи в объекты `en` и `ru` в `script.js`
2. Добавить атрибут `data-i18n="ключ"` к элементу HTML
3. Для текста с HTML-разметкой использовать `data-i18n-html`

## Как добавить языково-зависимые блоки

Использовать атрибут `data-lang-only="ru"` для блоков, которые показываются только на определённом языке.

## Как добавить новый язык

1. Добавить ключи в объект `translations` в `script.js`
2. Добавить кнопку переключения языка в header
3. Добавить логику определения языка в `getSystemLanguage()`
